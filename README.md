# Практические работы по операционным системам — вариант A

Репозиторий содержит решения ПР-1–ПР-8 по методическим указаниям «Проектирование операционных систем», часть 3А.

## Структура

- `pr01/` — диагностика Linux и терминал
- `pr02/` — Bash, журналы и системные вызовы
- `pr03/` — процессы, `fork`, `wait`, zombie
- `pr04/` — потоки, общий счётчик и сетевой ввод-вывод
- `pr05/` — симулятор FCFS, SJF и Round Robin
- `pr06/` — блокировки, банковские переводы, производитель–потребитель
- `pr07/` — pipe, FIFO, сигналы и конвейер
- `pr08/` — deadlock, исправление порядка блокировок и алгоритм банкира

## Требования

- Ubuntu 22.04+ или WSL2 с Ubuntu
- Python 3.11+
- Bash
- Для `strace`: `sudo apt install strace`
- Для `shellcheck` (необязательно): `sudo apt install shellcheck`

Все Python-работы используют только стандартную библиотеку. Внешние Python-пакеты не требуются.

## Быстрый запуск

Из корня репозитория:

```bash
python3 pr02/stats.py
python3 pr03/fork_demo.py
python3 pr04/threads_demo.py
python3 pr05/sched.py --algo all pr05/data/set1.txt
python3 pr06/sync_demo.py
python3 pr07/pipe_demo.py
python3 pr08/banker.py pr08/data/bank1.txt
```

У каждой практической работы есть собственный `README.md` с командами, пояснениями и ожидаемыми результатами.

## Важное замечание о фактических измерениях

Выводы `uname`, `ps`, `strace`, `/proc`, время выполнения и состояние служб зависят от конкретной машины. Скрипты получают их при запуске. В README не подставлены выдуманные результаты: запусти команды в своей Ubuntu и сохрани фактический вывод в отчёт.

Методичка сообщает, что шаблоны уровня A и наборы `data/`, `set1–3`, `bank1–2` преподаватель должен приложить отдельно. В этом репозитории для воспроизводимости созданы собственные совместимые входные данные и самостоятельные реализации задач уровня A. Они не выдаются за оригинальные файлы преподавателя.
