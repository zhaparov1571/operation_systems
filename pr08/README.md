# ПР-8. Взаимоблокировки

## Демонстрация deadlock

```bash
python3 pr08/deadlock_demo.py
```

Два потока захватывают `lock_a` и `lock_b` в разном порядке. Скрипт намеренно зависает. Остановить его можно через Ctrl+C. Это демонстрационный файл; не запускай его вместе с другими заданиями.

## Исправление

```bash
python3 pr08/deadlock_fixed.py
```

Исправление — единый порядок захвата блокировок. Так устраняется условие циклического ожидания: все потоки берут ресурсы в одинаковом порядке.

## Алгоритм банкира

```bash
python3 pr08/banker.py pr08/data/bank1.txt
python3 pr08/banker.py pr08/data/bank2.txt
python3 pr08/banker.py pr08/data/bank1.txt --request P1 1 0 2
```

Методичка указывает, что `bank1` — безопасное состояние с последовательностью `P1, P3, P4, P2, P0`, а `bank2` отличается Available=(0,1,0) и является небезопасным. В PDF матрицы Allocation и Max не напечатаны; поэтому в `data/` использованы классические матрицы учебного примера Silberschatz, на который ссылается методичка. Для этих матриц стандартный алгоритм находит последовательность `P1 -> P3 -> P4 -> P0 -> P2`. Это расхождение с указанной в PDF последовательностью нельзя проверить без исходных `bank1.txt`/`bank2.txt` преподавателя. Если преподаватель выдаст эти файлы, замени содержимое `data/` ими и запусти алгоритм повторно.

## Вывод

Deadlock возможен при одновременном выполнении четырёх условий: взаимное исключение, удержание и ожидание, отсутствие принудительного освобождения и циклическое ожидание. Единый порядок захвата блокировок предотвращает цикл.
