# ПР-2. Bash и системные вызовы

## Запуск

```bash
bash pr02/generate_logs.sh
bash pr02/stats.sh
```

Будет создано 50 файлов `pr02/data/01.log` … `50.log`, после чего скрипт посчитает строки `ERROR` по каждому файлу, общую сумму и файл с максимумом ошибок.

## Системные вызовы

Установи `strace`, если его нет:

```bash
sudo apt update && sudo apt install -y strace
strace -c ls
strace -c cat pr02/data/01.log
strace -e trace=openat cat pr02/data/01.log
```

`strace -c` показывает статистику системных вызовов. В типичном запуске встречаются `openat` (открыть файл/объект), `read` (прочитать данные), `close` (закрыть дескриптор), `newfstatat` (получить сведения об объекте), `mmap` (отобразить область памяти). Точный топ-3 зависит от версии системы, библиотек и команды — укажи фактический вывод своей машины.

`cat` открывает динамические библиотеки до целевого файла, потому что загрузчик должен подключить библиотеки, необходимые программе, прежде чем она начнёт выполнять свою основную работу.

## Контрольные вопросы

1. Пользовательская программа не обращается к диску напрямую, потому что устройства и доступ к ним контролирует ядро. Программа просит ядро выполнить операцию через системный вызов; ядро проверяет права и управляет устройством.
2. Системный вызов обычно дороже обычного вызова функции: требуется переход из пользовательского режима в режим ядра, проверка аргументов и выполнение операции с контролируемым доступом к ресурсам.
