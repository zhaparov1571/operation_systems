# ПР-7. Межпроцессное взаимодействие

## Pipe

```bash
python3 pr07/pipe_demo.py
```

Родитель создаёт pipe и дочерний процесс через `fork`. Ребёнок пишет строку, родитель читает. Каждый процесс закрывает неиспользуемый конец канала. Когда все концы записи закрыты, читатель получает EOF.

## FIFO

В первом терминале:

```bash
mkfifo /tmp/os_course_fifo
cat /tmp/os_course_fifo
```

Во втором:

```bash
echo hello > /tmp/os_course_fifo
```

`cat` ожидает, потому что FIFO — канал синхронного обмена: чтение ждёт писателя, а открытие на запись обычно ждёт читателя. После теста удали FIFO: `rm -f /tmp/os_course_fifo`.

## Сигналы

```bash
python3 pr07/signal_demo.py
```

Отправь сигнал из другого терминала: `kill -INT <PID>`, либо нажми Ctrl+C в терминале процесса. Обработчик выводит сообщение вместо стандартного завершения по SIGINT.
