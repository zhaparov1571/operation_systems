# ПР-6. Синхронизация

## Запуск

```bash
python3 pr06/sync_demo.py
```

Программа выполняет четыре части:

1. Четыре потока увеличивают счётчик с `threading.Lock`; ожидаемый результат — 400 000.
2. Сравнивается время инкремента с блокировкой и без неё. Отсутствие блокировки не гарантирует корректность.
3. Два потока переводят средства между счетами; критическая секция защищена одним lock, сумма счетов проверяется `assert`.
4. Производитель и потребитель работают через ограниченную `queue.Queue(maxsize=5)`. Когда очередь заполнена, `put()` блокируется до освобождения места.

Время выполнения зависит от компьютера; фиксированные цифры в отчёт не подставляются.
