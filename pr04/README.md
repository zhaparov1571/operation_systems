# ПР-4. Потоки

## Демонстрация общего счётчика

```bash
python3 pr04/threads_demo.py
```

Четыре потока по 100 000 раз увеличивают общую переменную. Запусти скрипт пять раз и внеси пять фактических результатов в отчёт. В CPython результат на практике может оказаться 400 000 из-за особенностей GIL и конкретной версии интерпретатора; само по себе это не является гарантией корректной синхронизации. Для демонстрации гонки в ПР-6 используется явная блокировка.

## Проверка потоков ядром

Во время работы процесса:

```bash
cat /proc/<PID>/status | grep '^Threads:'
ls /proc/<PID>/task
```

## Сравнение последовательной и параллельной загрузки

Создай файлы для локального HTTP-сервера и запусти сервер в первом терминале:

```bash
python3 pr04/prepare_downloads.py
cd pr04/webroot
python3 -m http.server 8000
```

Во втором терминале:

```bash
python3 pr04/download_demo.py
```

Скрипт скачивает 20 небольших файлов сначала последовательно, затем четырьмя потоками. Сетевой ввод-вывод позволяет потокам перекрывать ожидание ответа; поэтому потоки часто дают выигрыш. Время зависит от компьютера и окружения.
