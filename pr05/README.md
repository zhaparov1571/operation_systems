# ПР-5. Симулятор планирования CPU

## Реализовано

- FCFS — первым пришёл, первым обслужен
- SJF — невытесняющий выбор минимального `burst`
- RR — круговое планирование с заданным квантом

Для каждого процесса рассчитываются ожидание и оборот. Диаграмма Ганта печатается в консоль.

## Запуск

```bash
python3 pr05/sched.py --algo all pr05/data/set1.txt
python3 pr05/sched.py --algo rr --quantum 3 pr05/data/set1.txt
python3 pr05/sched.py --algo all pr05/data/set2.txt
python3 pr05/sched.py --algo all pr05/data/set3.txt
```

`set1.txt` совпадает с контрольным набором из методички. Для set2 и set3 добавлены данные из таблицы на страницах 9–10 PDF. Результаты можно сравнить с контрольными значениями для set1:

| Алгоритм | Среднее ожидание | Средний оборот |
|---|---:|---:|
| FCFS | 8.75 | 15.25 |
| SJF | 7.75 | 14.25 |
| RR (q=3) | 13.5 | 20.0 |

Если результаты отличаются, проверь соглашение RR: процесс, прибывший в момент окончания кванта, ставится в очередь раньше вытесненного процесса.
