# ПР-1. Диагностика Linux и знакомство с терминалом

## Цель
Проверить Linux-окружение, базовые команды, каталоги, файлы и Git.

## Выполнение

```bash
bash pr01/capture_env.sh
```

Скрипт выведет `whoami`, `pwd`, `uname -a`, `lsb_release -a` (если команда установлена), создаст `~/os-course/pr01/about.txt`, допишет вторую строку и покажет `ls -la`.

Для установки необходимых пакетов:

```bash
sudo apt update
sudo apt install -y git python3 build-essential
```

## Команды вручную

```bash
mkdir -p ~/os-course/pr01
cd ~/os-course/pr01
echo "Практическая работа №1" > about.txt
echo "Знакомство с Linux и терминалом" >> about.txt
cat about.txt
ls -la
```

## Объяснение столбцов `ls -la`

Для обычного длинного формата: тип файла и права доступа; число жёстких ссылок; владелец; группа; размер в байтах; дата и время изменения; имя файла. Первая колонка также содержит тип объекта (`-` для обычного файла, `d` для каталога).

## Что приложить в сдачу

Скопируй фактический вывод `bash pr01/capture_env.sh` в этот README или сохрани его отдельным файлом. Не вставляй примерные значения: имя пользователя, путь, ядро и права зависят от твоей системы.

В варианте A отдельные теоретические вопросы не заданы. Главное требование — текстовый вывод команд и объяснение столбцов `ls -la`.
