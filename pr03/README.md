# ПР-3. Процессы в Linux

## Запуск и наблюдение

```bash
ps -eo pid,ppid,stat,cmd --forest | head -40
sleep 300 &
ps -o pid,ppid,stat,cmd -p "$!"
cat "/proc/$!/status" | grep -E '^(State|VmRSS|Threads):'
kill "$!"
```

В отчёте укажи PID 1 и имя процесса из своего вывода, а также PID bash и PPID. Они различаются в разных окружениях (особенно в WSL и контейнерах).

## Демонстрации

```bash
python3 pr03/fork_demo.py
python3 pr03/zombie_demo.py
```

Для zombie открой второй терминал и выполни команду, которую напечатает скрипт, либо наблюдай:

```bash
ps -o pid,ppid,stat,cmd --ppid <PID_РОДИТЕЛЯ>
```

Скрипт удерживает родителя некоторое время, чтобы можно было увидеть состояние `Z`.

## Пояснение

Зомби — завершившийся дочерний процесс, запись о котором остаётся в таблице процессов, пока родитель не заберёт его статус через `wait()`/`waitpid()`. После завершения родителя сироту перенимает процесс-посредник (обычно PID 1 / init, в зависимости от среды), который затем забирает статус завершения.
